# university-java-projects
Two Java programming projects completed for a university Programming Concepts unit, covering core language fundamentals and object-oriented design.

## Projects

### [Project 1 – Arrays, Loops & Methods](./project1-arrays-methods)
A console program demonstrating array/ArrayList handling, custom sorting logic, and user input via dialogs.

### [Project 2 – Supermarket OOP System](./project2-supermarket-oop)
An object-oriented supermarket purchasing simulation using inheritance and polymorphism, with both a console version and a Java Swing GUI version.

## Tech Stack
- Java
- Java Swing (GUI)
