# Project 1 – Arrays, Loops & Methods

Console-based Java program demonstrating loops, custom sorting, and array/ArrayList handling.

## Files
- `Name.java` — reads names via input dialog into an ArrayList, sorts them alphabetically, and displays them.
- `Ages.java` — similar program that reads ages into an array and finds/displays the minimum age.

## How to Run
javac Name.java
java Name

javac Ages.java
java Ages
